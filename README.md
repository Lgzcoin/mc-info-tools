# MC 信息工具（mc-info-tools）

Minecraft 26.2 / Fabric 客户端模组：**只采集、只显示**，不改背包、不动方块、不需要 OP。

和自动挖矿（[mc-auto-miner](https://github.com/Lgzcoin/mc-auto-miner)）分开维护，同一个 mods 文件夹可共存。

## 已实现（v1.6.0）

| 模块 | 做什么 | 命令 |
|---|---|---|
| 资产日报 | 每 60 秒把「背包 + 仓库索引.txt 的箱子」加起来，和上次比，变化记流水，当天汇总 | `/info assets`、`/info assets snap\|log\|reset` |
| 掉落物倒计时 | 附近 32 格掉落物按原版 5 分钟规则倒计时，快消失提前提醒 | `/info drops` |
| 死亡点 | 死的一瞬间记坐标，报距离和方向 | `/info death` |
| 关键词告警 | 聊天出现关键词 → 聊天框提示 + 响一声 + 记文件 | `/info alert`、`/info alert add 词`、`/info alert test 话` |
| 聊天市场比价 | 听聊天报价，统一换成“每个多少钱”，攒行情；卖价低于历史均价就提醒 | `/info price`、`/info price 钻石`、`/info price cheap`、`/info price alert 阈值` |
| 商店广告索引 | 聊天出现「商店/促销/甩卖…」等触发词就存整条广告，之后一键搜索 | `/info shop`、`/info shop 钻石`、`/info shop add 词` |
| 屏幕悬浮板 | 左上角常驻信息板（服务器/延迟/在线、资产、掉落、死亡点、行情、广告数），按 `I` 开关 | 按 `I`，或 `/info hud on\|off` |
| 服务器信息 | 服务器名、在线人数与名单、你的延迟 | `/info server` |
| 物品速查卡 | 准星/背包指着物品按 V，弹出物品 ID、耐久、行情卖/收、附近最低价店、这格估值 | 默认 V，可在控制里改；不再自动弹 tooltip |
| 告示牌商店地图 | 走近自动扫告示牌商店，记物品、收购/出售价、坐标；查最近最便宜的店 | `/info sign`、`/info sign 钻石`、`/info sign near`、`/info sign scan` |
| 背包市值 | 背包数量 × 行情卖中位，算总市值和最值钱 5 样；另给商店最高收价估值 | `/info worth` |
| 全服收购榜 | 告示牌店 + 聊天收价合成收购榜，查最高收价和坐标 | `/info buy`、`/info buy 钻石` |
| 搬砖套利 | 最便宜卖店 → 最高收价，算利润率和路线 | `/info flip` |
| 补货清单 | 目标库存 → 缺口 → 最便宜店 → 贪心采购顺序 | `/info stock`、`/info stock set 钻石 64`、`/info stock plan` |
| 开箱索引 | 打开过的箱子/木桶/潜影盒内容，查物品在哪 | `/info chest 钻石` |
| 行情日线 | 每天第一次进游戏快照行情，查 7 日均价 | `/info history 钻石` |
| 死亡损失 | 死亡按背包行情估损失，提示值不值得回去捡 | `/info loss` |
| 挂机收益 | 每分钟记背包净增/经验，按小时汇总 | `/info income` |
| 店主订阅 | 关注店主，聊天说话/上新/降价提醒 | `/info watch add 名字` |
| 配方/用途 | 客户端配方书查合成材料和用途 | `/info recipe 钻石` |
| 报价快捷 | 报价后补一行可点击复制的 `/msg` 回复 | 点聊天里的 `[报价]`，或 `/info quote copy` |
| 状态文件 | 每 5 秒写 `信息状态.txt`，外部工具可读 | — |

## 安装

1. 下载 Release 里的 `infotools-<版本>.jar`，丢进 `.minecraft/mods`
2. 需要 Fabric API 与 Java 25
3. 进世界后 `/info`

详细用法见 [docs/使用说明.txt](docs/使用说明.txt)。配置在游戏目录 `信息工具配置.txt`，改完 `/info reload` 立即生效。

## 生成的文件

按账号分开存放：`游戏目录/信息工具/<玩家名>/`，多开时几个号不会互相覆盖。

`资产总计.txt`、`资产变动.txt`、`资产日报.txt`、`资产今日.txt`、`资产历史.txt`、`死亡点.txt`、`告警记录.txt`、`行情.txt`、`商店广告.txt`、`商店地图.txt`、`信息状态.txt`

配置是全局一份：`游戏目录/信息工具配置.txt`

## 已知限制（不是 bug）

- 只读客户端可见数据，不查询服务端，不需要 OP。
- 客户端拿不到掉落物真实出生时间，倒计时用实体 `tickCount` 估算；刚进服就存在的旧掉落物会偏久（最多 5:00）。
- 仓库只认已写入 `仓库索引.txt` 的箱子；存进未索引的箱子会先显示成支出，下一轮扫描会补回。
- 比价依赖聊天原文：太口语/太绕的说法识别不了；有人恶意喊低价会误导，只当参考。
- 商店广告只是把别人喊的话存档，不自动私聊、不自动跑过去，也不判断真假。
- 行情按服务器分开统计（用服务器 ip 区分），单机显示为「单人」；换服后看到的是新服的价。
- 商店地图只认「告示牌上有物品名 + 价格」的店；ChestShop 第四行没写物品名（物品在箱子里）的店识别不了。
- 告示牌不显示库存，商店地图只比价格和距离，不保证去了还有货；ChestShop 的 B=店收、S=店卖，QuickShop 的 Buy=你买、Sell=你卖，第一次用先核对方向。
- 背包市值不含潜影盒内容，也不等于实际能卖出去的价格。
