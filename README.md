# MC 信息类工具（mc-info-tools）

和「自动干活」分开的一块：只采集信息、只显示，不乱动游戏。

## 计划收录
- 资产盘点：每个号背包 + 仓库总资产，按天出日报（挖了多少、什么时候少了）
- 掉落物消失倒计时 + 死亡点导航
- 潜影盒 / 箱子内容速览
- 在线玩家记录（谁什么时候上线、待多久）
- 聊天市场比价（监听 收/卖/价格，攒行情，低于均价提醒）
- 实体密度 / 刷怪效率统计
- 服务器状态（延迟、在线人数、重启周期）
- 关键词告警（管理员点名、清人、重启、封号）
- 游戏内时间与天黑提醒、药水状态计时

## 约定
- 客户端模组独立 mod id，命令前缀 `/info`
- 数据一律写 `游戏目录\*.txt`，UTF-8，一行一条，便于外部工具读
- 不依赖服务端插件、不需要 OP

## 版本
Minecraft 26.2 / Fabric，Java 25
